# Architecture Decision Records

ADRs capture durable decisions that affect multiple Finvera features or are
costly to reverse. Number files sequentially as `NNNN-short-title.md` and copy
`0000-template.md` as the starting point.

Statuses are `Proposed`, `Accepted`, `Superseded`, or `Deprecated`. Never edit an
accepted ADR to reverse its decision; add a new ADR and link both records.
