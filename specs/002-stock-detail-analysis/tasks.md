# Tasks: Stock Detail and Analysis

**Input**: Design artifacts from `specs/002-stock-detail-analysis/`
**Required**: `spec.md`, `plan.md`, `research.md`, `data-model.md`, `contracts/`,
and `quickstart.md` — all present.
**Goal**: Deliver a fixture-first stock detail vertical slice (overview, chart,
technical, fundamentals, valuation) without guessing provider behavior. Gates
G-01 to G-04 (`research.md` R-012) stay outside the fixture critical path;
Phase 6 tasks MUST NOT start merely because fixture mode is complete.

## Task Format

```text
- [ ] T001 [P?] [US?] [Requirement IDs] Action with exact file path
      Verify: command or observable completion evidence
      Depends: task IDs or "none"
```

`[P]` marks tasks that touch different files with no unmet prerequisite.
`[US1]`/`[US2]`/`[US3]` map a task to its user story; setup and foundation
tasks carry no story label. Every behavior task cites requirement IDs and an
exact path. Tests are written before or alongside the behavior they cover.
